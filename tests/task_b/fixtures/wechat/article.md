# Agent 越聪明，为什么越需要一份任务合同

过去我们把提示词写得越来越长，像给一个高手塞进一本操作手册。

真正的问题不是模型不会做，而是双方没有说清楚什么叫完成。

{{IMAGE:img-contract-cover}}

## Prompt 在描述动作，任务合同在约定结果

Prompt 常常告诉模型先做什么、再做什么。任务合同则说明输入、交付物、验收标准和失败时怎么停。

这像装修：你不用教木工每一锤怎么敲，但必须把尺寸、材料和验收方式写清楚。

## 一份够用的合同只有四件事

- 输入是什么，哪些证据可信
- 最终交付什么文件
- 什么条件算通过
- 遇到缺口时如何失败

**AI 越强，过程可以越薄；结果边界必须越清楚。**
