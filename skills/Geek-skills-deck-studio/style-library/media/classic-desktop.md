# 经典桌面

- **一句话定位**：Windows 95 灰色窗口 + 像素字体，复古操作系统怀旧感
- **适用场景**：科技怀旧主题、开发者社区、Y2K 前数字文化、复古品牌
- **不适用场景**：严肃商务汇报、高端品牌、需要现代感的场合
- **色板**：`#C0C0C0`（桌面灰）/ `#000080`（经典蓝标题栏）/ `#FFFFFF`（白）/ `#000000`（黑文字）
- **字体气质**：MS Sans Serif 或等宽像素字体；标题栏用系统字；无现代字体
- **版式特征**：矩形窗口框架；蓝色标题栏 + 灰色窗体；像素级按钮（最小化/最大化/关闭）；窗口可层叠；底部状态栏
- **图像倾向**：低色深图标（16 色风格）；像素艺术；避免高清照片；图标 16×16 或 32×32 像素网格
- **页面密度**：中；窗口内容清晰可读
- **标题语气**：系统提示式，"任务已完成"或"正在加载..."式
- **image2 适配**：适合（像素风格、直角元素易渲染）
- **直接导出 PPT**：适合（注意字体 fallback）

## Style Brief（注入生成器）

Windows 95 复古桌面风格：桌面灰底色，内容装在经典蓝标题栏的窗口框内，像素级系统按钮（最小化/最大化/关闭），MS Sans Serif 或等宽像素字体，16 色风格低色深图标，窗口可层叠，底部灰色状态栏，整体复刻 1995 年操作系统界面——怀旧、像素、零圆角。

## 页型配方

- **封面**: 桌面灰底，一个大窗口居中（蓝色标题栏 "Welcome" + 窗口按钮），窗口内显示标题文字，可选桌面图标（回收站/我的电脑）在背景
- **数字页**: 一个窗口，蓝色标题栏显示类别名，窗口内一个大数字 + 说明文字，状态栏显示辅助信息，窗口有 3D bevel 边框
- **分屏/内容页**: 2-3 个窗口（可重叠或平铺），每个窗口有完整 chrome（标题栏 + 边框 + 按钮），窗口内显示列表或文字
- **收尾**: "操作完成"对话框窗口，OK 按钮，桌面背景可见

## 禁止构图

- **平面卡片**（无 3D bevel 和窗口 chrome） — 失去 Windows 95 立体窗口签名
- **圆角矩形** — Windows 95 是纯直角
- **现代扁平化图标**（渐变/高清/阴影） — 必须 16 色像素图标或 3D 小立体图标
- **无标题栏的内容区** — 标题栏（蓝底白字 + 3 个按钮）是窗口身份
- **无 3D bevel 的边框** — 窗口必须有立体边框（明暗两侧 bevel）
