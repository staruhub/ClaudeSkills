# 画布彩章

- **一句话定位**：奶油画布底 + 大胆彩色印章，杂志海报能量感
- **适用场景**：品牌提案、创意展示、设计工作室介绍、文化活动策划
- **不适用场景**：财务汇报、政府正式场合、学术答辩
- **色板**：`#F5F1E8`（奶油画布）/ `#111111`（黑）/ `#1B5E20`（森林绿）/ `#D81B60`（鲜粉）
- **字体气质**：超粗黑体大标题（Archivo Black 或思源黑体 Heavy）；正文 Medium；数字保持粗重
- **版式特征**：侧边竖向色块如印章；大标题占据主视觉；彩色块不规则摆放；画布纹理底；边缘色块可穿出页面
- **图像倾向**：少图；图像如盖章般摆放；保留画布底色透气感；拒绝细腻渐变
- **页面密度**：中低；一页一个视觉焦点
- **标题语气**：宣言式短句，"设计即态度"式
- **image2 适配**：非常适合（大块平涂 + 粗字是舒适区）
- **直接导出 PPT**：适合

## Style Brief（注入生成器）

画布彩章风格：奶油色纸质画布背景，森林绿或鲜粉色大面积色块如印章般出现在页面侧边或角落，黑色超粗标题主导视觉，竖向色块可穿出页面边界制造张力，整体像杂志海报——大胆、有态度、印刷质感强烈。

## 页型配方

- **封面**: 奶油画布底，黑色超粗大标题占左侧或中央，右下或左上角一个不规则色块（森林绿或鲜粉）如盖章，色块可穿出页面边界
- **数字页**: 奶油底，一个黑色大数字（≥80pt），侧边或角落一个竖向/斜向彩色块（不规则形状），色块不覆盖数字，像盖在纸上的印章
- **分屏/内容页**: 画布底，黑色标题 + 内容，页面某一侧/角落有彩色块点缀，色块位置逐页变化（不固定）
- **收尾**: 金句用黑色，角落彩章色块

## 禁止构图

- **每页都有的 full-height 左/右色条**（持续性侧边栏 chrome） — 印章是"不规则、逐页变化位置"，不是导航栏
- **规则的矩形 sidebar** — 印章是不规则色块，可以是竖条、斜块、角落方块，但不是工整的 UI sidebar
- **对称居中构图** — 画布彩章是不对称的（印章盖在一侧或角落）
- **彩色块覆盖/裁切主要内容** — 印章是装饰锚点，不遮挡标题或数字
- **色块在所有页面同一位置** — 逐页变化位置才像盖章，固定位置是 chrome
