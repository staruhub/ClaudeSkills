# 糖盒彩框

- **一句话定位**：软霓虹色块 + 粗黑描边，Neo-Brutalist 高能量感
- **适用场景**：创意提案、品牌介绍、校园/活动策划、青年向产品、开发者社区
- **不适用场景**：严肃财报、政府汇报、高管例会、传统企业
- **色板**：`#FFFFFF`（白底）/ `#98FF98`（薄荷绿）/ `#FFFFB3`（软黄）/ `#FFB3BA`（桃粉）/ `#111111`（粗黑描边）
- **字体气质**：粗黑体标题（思源黑体 Bold）+ 常规正文；数字保持粗重
- **版式特征**：内容装在 3-4px 粗黑描边的色块中；软霓虹色块（薄荷/软黄/桃粉）轮换；描边硬朗、色彩柔和形成对比；可轻微旋转
- **图像倾向**：插画或平涂图形；粗描边处理；拒绝细腻照片；装饰性元素需有黑描边
- **页面密度**：中；色块多但每块内容集中
- **标题语气**：轻快短语，"先看三件小事"式
- **image2 适配**：非常适合（粗描边 + 平涂色块是舒适区）
- **直接导出 PPT**：适合

## Style Brief（注入生成器）

Neo-Brutalist 糖盒风格：白色背景，内容装在 3-4px 粗黑描边的色块中，薄荷绿/软黄/桃粉等软霓虹色大面积使用，粗黑体标题，元素可轻微旋转，整体硬边框配柔和色彩——高能量、年轻、有态度但不粗暴。

## 页型配方

- **封面**: 白底，几个粗黑描边色块（薄荷/软黄/桃粉）不规则排列，主标题在最大色块内，副标题在小色块，可轻微旋转（≤3°）
- **数字页**: 2-3 个粗黑描边卡片，每卡一个大数字 + 标签，色块交替用薄荷/桃粉，轻微错位或旋转但保持在 1280×720 内
- **分屏/内容页**: 阶段卡（L12）或原则卡（L08），每卡 3-4px 黑描边 + 软霓虹底色，卡内标题 + 列表（≤5 条）
- **收尾**: 金句在粗黑描边色块内，可选装饰性小色块点缀

## 禁止构图

- **细边框或无边框卡片**（< 2px 或无描边） — 失去 Neo-Brutalist 粗黑边签名
- **表格**（如 L07，细线表格 <2px） — 表格线条太细，不符合糖盒粗描边
- **完全整齐的网格对齐** — Neo-Brutalist 允许轻微错位/旋转制造手工感，但不能混乱
- **细腻渐变或照片** — 糖盒是平涂 + 插画，拒绝细腻质感
- **单色或双色** — 必须有 ≥3 种软霓虹色轮换，否则失去"糖盒"感
