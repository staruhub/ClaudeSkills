# 珊瑚夜色

- **一句话定位**：近黑底 + 珊瑚奶油大字，暗色高对比路演感
- **适用场景**：产品路演、夜场发布会、高端提案、品牌故事
- **不适用场景**：教学课件、数据密集汇报、明亮场地投影
- **色板**：`#1A1A1A`（深炭黑底）/ `#FF7F50`（珊瑚）/ `#F5F0E6`（奶油白）/ `#B0B0B0`（浅灰）
- **字体气质**：超粗无衬线特大标题（Bebas Neue 或 Impact）+ 正文 Regular；标题可达 120pt+
- **版式特征**：暗底主导；珊瑚色和奶油色交替用于标题；偶有整页浅色反转页；标题超大占据 1/2 以上画面；留白大胆
- **图像倾向**：少图；暗调照片或单一明亮物体；高对比处理；拒绝复杂场景
- **页面密度**：极低；一页一句话或一个大数字
- **标题语气**：短句宣言，"未来，现在开始"式
- **image2 适配**：非常适合（暗底大字是 image 模型强项）
- **直接导出 PPT**：适合（需注意投影环境亮度）

## Style Brief（注入生成器）

珊瑚夜色风格：深炭黑背景，奶油白或珊瑚色超粗特大标题（Bebas Neue）占据页面主体，偶尔整页反转为浅色，高对比暗调图像，元素稀疏、留白极致，整体像夜场发布会大屏——戏剧化、高冲击、适合暗场投影。
