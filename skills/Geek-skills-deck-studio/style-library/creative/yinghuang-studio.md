# 荧黄工作室

- **一句话定位**：黑底配电光黄大字，高能设计工作室感
- **适用场景**：策略提案、品牌方案、咨询汇报、高客单价销售
- **不适用场景**：教学课件、政府汇报、数据密集型财报
- **色板**：`#0D0D0D`（深黑底）/ `#E8B004`（暖黄强调）/ `#F5F0E6`（米白文字）/ `#3D3D3D`（分隔）
- **字体气质**：超粗黑体大标题（思源黑体 Heavy）+ 细体正文；中英混排时英文用 Montserrat
- **版式特征**：大字、低密度、强标题主导；暗底上的黄色关键词高亮；不对称留白构图
- **图像倾向**：少图；大面积暗底 + 单点题视觉（一个物体/一个隐喻图像）；照片压暗处理
- **页面密度**：低；一页一句话一个视觉
- **标题语气**：宣言式短句，"把复杂留给我们"式
- **image2 适配**：非常适合（低密度大字是 image 模型的舒适区）
- **直接导出 PPT**：适合，但需嵌入字体

## Style Brief（注入生成器）

高端黑金提案风格：近黑深色背景，米白色超粗黑体大标题占据视觉中心，暖黄色只用于关键词高亮和细线装饰，页面元素稀疏、留白大胆不对称，配图为单一压暗的点题视觉物，整体气质昂贵、笃定、有提案说服力。

## 页型配方

- **封面**: 黑底，左侧大标题（米白 Heavy），一个关键词用暖黄高亮，右侧单一点题视觉物（压暗处理）
- **数字页**: 一个大数字（暖黄或米白，≥80pt） + 一句话结论（≤20 词），无三联数据带，最多 1-2 个小辅助数字
- **分屏/内容页**: 阶段卡（L12）可用但单卡列表 ≤5 条；或单列一句话 + 一个隐喻视觉
- **收尾**: 短句金句（米白），一个暖黄关键词，幽灵符号

## 禁止构图

- **3 列或 2 列并列 KPI 卡片** — 违反"一页一句话一个视觉"
- **瑞士表格**（L07） — 表格 = 数据密集，荧黄是低密度大字风格
- **≥4 行的 bullet list 或行动行** — 密度过高
- **任何页面 > 30 词** — 违反"低密度"定位
- **咨询三栏 dashboard 换皮**（如三个并列数据卡 with different numbers but same structure） — 蒙住色板认不出是荧黄还是 polar-night
