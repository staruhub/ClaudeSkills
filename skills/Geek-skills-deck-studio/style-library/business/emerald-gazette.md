# 翡翠公报

- **一句话定位**：翡翠绿 + 深海军蓝，杂志刊头式商务模板
- **适用场景**：季度公报、商业杂志式汇报、品牌年报、编辑型内容
- **不适用场景**：科技产品、青年文化、需要轻快感的场合
- **色板**：`#50C878`（翡翠绿）/ `#1B3A52`（深海军蓝）/ `#FFFFFF`（白）/ `#111111`（黑）
- **字体气质**：翡翠绿或深蓝粗衬线标题（如 Playfair Display 或宋体 Bold）+ 无衬线正文；刊头可用装饰字
- **版式特征**：页面顶部翡翠绿或深蓝色刊头带；标题用衬线字体；多栏排版；页码做成期刊样式；纸质纹理底
- **图像倾向**：编辑式照片（人物/场景）；照片裁切严格（矩形框）；图说文字必有；拒绝卡通插画
- **页面密度**：中高（杂志式容纳内容）
- **标题语气**：编辑标题，"2026：增长的新逻辑"式
- **image2 适配**：适合（版式规整、编辑感强）
- **直接导出 PPT**：适合

## Style Brief（注入生成器）

翡翠公报风格：白色纸质底，翡翠绿和深海军蓝交替用于刊头带和标题，粗衬线字体标题配无衬线正文，多栏编辑式排版，照片严格矩形裁切配图说，页码做成期刊样式，整体像一本商业杂志封面——编辑性强、专业、有分量感。

## 页型配方

- **封面**: 白底，顶部翡翠绿或深蓝刊头带（masthead band，含期刊名/期数/日期），下方大标题（衬线字，翡翠绿或深蓝），可选主视觉照片（矩形框）
- **数字页**: 刊头带（翡翠绿底白字，显示栏目名），左栏大数字（深蓝或翡翠绿，衬线字），右栏 editorial rail（深海军蓝或灰色辅助文字，两栏编辑排版）
- **内容页**: 两栏 editorial layout（左栏主要内容，右栏图说/辅助），刊头带持续，照片矩形裁切 + 图说文字
- **收尾**: 刊头带 + 金句（衬线字），期刊式页码

## 禁止构图

- **无刊头 band 的页面** — masthead band（顶部色带）是期刊身份，至少封面和关键页要有
- **单列居中大字** — 那是路演风格（如 coral-night），公报是两栏 journal layout
- **卡片 dashboard**（如 Bento 三卡、L04） — 那是咨询风格，翡翠公报是期刊编辑排版
- **无衬线标题** — 翡翠公报标题必须衬线（Playfair, 宋体），这是杂志质感
- **卡通插画或装饰图形** — 公报是编辑式照片（人物/场景）+ 矩形框 + 图说
