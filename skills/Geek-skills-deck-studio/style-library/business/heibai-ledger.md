# 黑白账本

- **一句话定位**：象牙纸质感 + Lora 标题 + Jost 正文，典雅数据账本
- **适用场景**：财报/经营数据汇报、OKR 复盘、预算评审、周期性数据例会
- **不适用场景**：品牌故事、路演开场、情绪调动型内容
- **色板**：`#F6F1E8`（象牙纸底）/ `#111111`（文字与表格线）/ `#E8E4DC`（隔行底纹）/ `#0B6E4F`（增长绿）/ `#B3261E`（下降红）——红绿只用于数据方向
- **字体气质**：标题 Lora 衬线字体（或思源宋体）；正文 Jost 无衬线（或思源黑体）；数字用等宽或 DIN，小数点对齐
- **版式特征**：表格是一等公民；细横线多、竖线少；大数字页（big-number）与表格页交替；页脚有数据口径注释
- **图像倾向**：几乎无图；图表只用柱状/折线/瀑布三种，拒绝 3D 和环形装饰
- **页面密度**：中高（数据场景允许密，但一页仍只回答一个问题）
- **标题语气**：口径精确的结论句，"营收同比 +18%，增速连续两季放缓"式
- **image2 适配**：不适合（表格渲染不可靠），此风格默认模式 B
- **直接导出 PPT**：非常适合

## Style Brief（注入生成器）

数据账本风格：纯白背景，黑色细线表格为版面主体，隔行浅灰底纹，数字用等宽字体右对齐，绿色仅表示增长、红色仅表示下降，图表限定柱状/折线/瀑布图且无任何 3D 或装饰效果，页脚小字注明数据口径，整体像一份严谨的印刷财报。

## 页型配方

- **封面**: 象牙纸底，Lora 衬线标题（深黑），底部元信息用 Jost，可选细横线分隔
- **数字页**: 必须是表格（L07 瑞士对比表或自定义表格），斑马纹隔行底纹（#E8E4DC），数字等宽右对齐、小数点对齐，红绿仅用于 +/− 方向，页脚口径注释
- **图表页**: L14 曲线论证，限柱状/折线/瀑布图，灰色 + 单强调色（绿/红），无 3D/阴影/背景纹理
- **收尾**: 简洁文字结论，可选表格摘要，无装饰图形

## 禁止构图

- **巨型时尚数字**（≥100px 无表格上下文的孤立大数字，如 L09 fashion hero number） — 账本是表格公民，不是路演大字
- **卡片式 dashboard**（如 Bento 三卡、原则卡组） — 卡片 = 创意风格，账本是纸质表格印刷感
- **无表格的纯文字对比页** — 对比必须在表格里，用细线和底纹区分
- **3D 图表 / 环形图 / 雷达图** — Tufte chartjunk 零容忍
- **整列涂色** — 强调失效，只在关键单元格用色
