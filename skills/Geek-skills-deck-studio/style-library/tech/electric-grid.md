# 电光网格

- **一句话定位**：方格纸底 + 电光钴蓝衬线字 + 像素故障条，科技实验感
- **适用场景**：AI/科技产品、数据可视化、技术报告、开发者大会
- **不适用场景**：传统企业汇报、温暖人文主题、非技术受众
- **色板**：`#FFFFFF`（白底）/ `#0047AB`（钴蓝）/ `#E0F7FF`（天蓝浅底）/ `#111111`（黑）
- **字体气质**：钴蓝色衬线字体标题（如 IBM Plex Serif）+ 等宽字体正文/代码；数字必用等宽
- **版式特征**：浅色方格纸网格背景（5px 或 10px）；细蓝色水平/竖直辅助线；像素风故障条点缀；数据区用网格对齐
- **图像倾向**：图表/代码块/数据表为主；矢量图标；线框图；拒绝照片；允许 ASCII art 或像素图
- **页面密度**：中高（技术内容允许密度）
- **标题语气**：技术陈述，"算法性能提升 40%"或"Model Architecture"式
- **image2 适配**：适合（几何风格、清晰网格易渲染）
- **直接导出 PPT**：适合

## Style Brief（注入生成器）

电光网格风格：白色或浅天蓝背景叠加细线方格网格，电光钴蓝色衬线字体标题，等宽字体正文，水平或竖直细蓝线作辅助，偶有像素风故障条装饰，图表和数据网格对齐，整体像一张实验室方格纸——理性、精确、科技感强烈。
