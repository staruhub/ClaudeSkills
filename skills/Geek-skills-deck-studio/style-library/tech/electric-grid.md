# 电光网格

- **一句话定位**：方格纸底 + 电光钴蓝衬线字 + 像素故障条，科技实验感
- **适用场景**：AI/科技产品、数据可视化、技术报告、开发者大会
- **不适用场景**：传统企业汇报、温暖人文主题、非技术受众
- **色板**：`#FFFFFF`（白底）/ `#0047AB`（钴蓝）/ `#E0F7FF`（天蓝浅底）/ `#111111`（黑）
- **字体气质**：钴蓝色衬线字体标题（如 IBM Plex Serif）+ 等宽字体正文/代码；数字必用等宽
- **版式特征**：浅色方格纸网格背景（5px 或 10px）；细蓝色水平/竖直辅助线；像素风故障条点缀；数据区用网格对齐
- **图像倾向**：图表/代码块/数据表为主；矢量图标；线框图；拒绝照片；允许 ASCII art 或像素图
- **页面密度**：中高（技术内容允许密度）
- **标题语气**：技术陈述，"算法性能提升 40%"或"Model Architecture"式
- **image2 适配**：适合（几何风格、清晰网格易渲染）
- **直接导出 PPT**：适合

## Style Brief（注入生成器）

电光网格风格：白色或浅天蓝背景叠加细线方格网格，电光钴蓝色衬线字体标题，等宽字体正文，水平或竖直细蓝线作辅助，偶有像素风故障条装饰，图表和数据网格对齐，整体像一张实验室方格纸——理性、精确、科技感强烈。

## 页型配方

- **封面**: 方格纸背景（浅灰 1px 网格 5-10px 间距），钴蓝衬线标题（≥60pt），右下或左上角有 4-8px 像素故障条（钴蓝或电光黄），细蓝辅助线穿过标题
- **数字页**: 方格纸背景，一个大数字（钴蓝，等宽字体，≥80pt），数字对齐网格，旁边有 4-8px 像素故障条，底部 1-2 行辅助数字（等宽），可选小图表对齐网格
- **图表/表格页**: L07 表格或 L14 图表，数据对齐方格网格，钴蓝标题（衬线），数字等宽，细线表格或图表轴线
- **收尾**: 金句用钴蓝衬线，方格纸背景，故障条装饰

## 禁止构图

- **无网格背景的页面** — 方格纸网格是电光网格的核心签名，每页必须有
- **非衬线字体标题** — 电光网格的签名是"科技 × 古典"对比，标题必须衬线（如 IBM Plex Serif, Playfair）
- **数字不是等宽或未对齐网格** — 数字必须等宽（如 Roboto Mono, Inconsolata），并对齐背景网格
- **无像素故障条装饰** — 每页至少有一处 4-8px 像素故障条（钴蓝或电光黄），这是"电光"元素
- **圆角卡片或柔和风格** — 电光网格是硬边、网格对齐、理性风格
