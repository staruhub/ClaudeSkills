# Style Identity — 风格身份门禁

> **Gate**: 蒙住色板，从构图仍能认出风格。低密度风格禁止套进咨询三栏 KPI 骨架换皮。
> 
> 来源：9 套 picker 风格 5 页 smoke deck 视觉 QA 发现**风格身份崩溃** bug（珊瑚夜色 / 荧黄工作室 / 画布彩章等被执行成"polar-night 三栏换皮"）。

## 判定方法

渲染后取 3 页：封面 + 数字页 + 最密页。

1. **灰度缩略测试**：转灰度，两个风格若无法区分 → FAIL
2. **构图签名检查**：该风格的版式特征（如"侧边印章" / "窗口 chrome" / "表格斑马纹"）是否存在
3. **密度合规**：风格文件声明"极低密度"但渲染成 3 栏 KPI dashboard → FAIL

## Picker 9 风格身份约束

### 珊瑚夜色 (coral-night)

- **允许 layout**: L01, L09, L13（封面/数据英雄/金句封底）
- **禁止 layout**: L04 Bento 三卡, L07 瑞士对比表, L11 行动行（密度违约）
- **数字页配方**: 一个巨型数字或等式占 ≥40% 画面高度，底部最多 3 个辅助数字，无多列列表
- **禁止构图**: 
  - 3 列 KPI dashboard
  - 左右对照 split-compare 文字列表
  - 任何密度 > 50 词/页的页面
  - 将 L09 数据英雄退化成带三个小卡片的咨询页

### 荧黄工作室 (yinghuang-studio)

- **允许 layout**: L01, L09, L12（有内容列表的阶段卡可用，但单卡 ≤5 条）, L13
- **禁止 layout**: L07 瑞士对比表, L04 Bento 三卡（三卡内容并列违反"一页一个视觉"）
- **数字页配方**: L09 数据英雄简化版：一个大数字 + 一句话结论（≤20 词），无三联数据带或仅 1-2 个辅助数字
- **禁止构图**:
  - 3 列或 2 列并列 KPI 卡片
  - 瑞士表格（表格 = 数据密集，违反"一页一句话一个视觉"）
  - ≥4 行的 bullet list 或行动行
  - 任何页面 > 30 词

### 黑白账本 (heibai-ledger)

- **允许 layout**: L07 瑞士对比表, L14 曲线论证（图表限柱状/折线/瀑布），L02（目录可以），L13
- **禁止 layout**: L09 数据英雄时尚大数字（账本是表格公民，不用 fashion hero number）
- **数字页配方**: 必须是表格（L07 或自定义表格）；斑马纹隔行底纹；小数点对齐；页脚口径注释
- **禁止构图**:
  - 巨型时尚数字（≥100px 无表格上下文的孤立大数字）
  - 卡片式 dashboard（卡片 = 创意风格，账本是纸质表格）
  - 无表格的纯文字对比页

### 糖盒彩框 (tanghe-frame)

- **允许 layout**: L04, L08 原则卡组, L12 阶段卡，所有卡片必须有 3-4px 黑色描边
- **禁止 layout**: L07 表格（表格无边框或细边框，违反"粗黑描边"签名）
- **数字页配方**: 2-3 张粗黑描边卡片，每卡一个数字 + 标签，卡片可轻微旋转（≤3°）但必须在 1280×720 内
- **禁止构图**:
  - 细边框或无边框卡片
  - 表格（线条 <2px）
  - 整齐网格对齐（Neo-Brutalist 允许微错位）

### 画布彩章 (huabu-stamp)

- **允许 layout**: L01, L09, L13; 侧边或角落色块作为视觉锚点
- **禁止 layout**: 持续性左侧/右侧 full-height sidebar（那是 chrome，不是印章）
- **数字页配方**: 奶油画布底，一个大数字，角落或侧边一个不规则色块（森林绿或鲜粉）如盖章，色块可穿出页面边界
- **禁止构图**:
  - 每页都有的 full-height 左/右色条（持续 chrome = 导航栏，不是印章）
  - 规则的矩形 sidebar
  - 对称居中构图（印章是不规则的）

### 经典桌面 (classic-desktop)

- **允许 layout**: L01 封面作为桌面壁纸, L04/L08/L12 卡片作为窗口
- **禁止 layout**: 无窗口 chrome 的纯文字页（失去桌面身份）
- **数字页配方**: 一个居中窗口，灰色标题栏（关闭/最小化/最大化按钮），3D bevel 边框，内容区显示数字，状态栏可选
- **禁止构图**:
  - 平面卡片（无 3D bevel 和窗口 chrome）
  - 圆角矩形（Windows 95 是直角）
  - 现代扁平化图标（必须 16 色像素图标或 3D 小图标）

### 电光网格 (electric-grid)

- **允许 layout**: L01, L07 表格（对齐网格）, L09, L14 图表
- **禁止 layout**: 无网格背景的页面
- **数字页配方**: 方格纸背景（浅灰 1px 网格），一个大数字用钴蓝衬线字体（如 Playfair），数字是等宽或对齐网格，页面某处有 4-8px 像素故障条（钴蓝或电光黄）
- **禁止构图**:
  - 无网格背景
  - 非衬线字体标题（电光网格的签名是"科技 × 古典"，必须衬线）
  - 数字不是等宽或未对齐网格
  - 无像素故障条装饰

### 钴蓝简报 (cobalt-brief)

- **允许 layout**: L01 with left cobalt rule, L02, L06, L09, L13
- **禁止 layout**: L07 表格（表格是账本的，简报用卡片和流程）
- **数字页配方**: 奶油纸底，一个钴蓝色大数字（衬线字体），左侧细钴蓝竖线（hairline 或 2-4px），结论段用深灰 sans-serif
- **禁止构图**:
  - 表格（那是 heibai-ledger）
  - 3 列密集 KPI（简报是"brief"，保持呼吸感）
  - 无左侧钴蓝脊线或竖线元素

### 翡翠公报 (emerald-gazette)

- **允许 layout**: L01 作为刊头封面, L02, L06, L13; 内页用两栏 editorial
- **禁止 layout**: 单列居中大字（那是路演风格，公报是期刊）
- **数字页配方**: 刊头（masthead band，翡翠绿底 + 期数/日期），右侧 editorial rail（深海军蓝），数字在左栏，辅助说明在右栏
- **禁止构图**:
  - 无刊头 band 的页面（失去期刊身份）
  - 单列居中（公报是两栏 journal layout）
  - 卡片 dashboard（那是咨询风格，不是期刊）

## 正交拆维的正确边界

`layout-registry.md` 说"同一 L05 可渲染成墨白/极夜/英黄三种质感"——这对**咨询三胞胎**（moshiro / polar-night / yinghuang-studio v2）是对的，因为它们都是"低密度咨询提案"类目。

**但**珊瑚夜色 vs 黑白账本 **不正交**：
- 珊瑚夜色 = 暗场路演，极低密度（10-30 词/页），巨标题
- 黑白账本 = 数据账本，中高密度（50-80 词/页），表格主导

执行"正交"为"把珊瑚夜色色板套在 L07 瑞士表格上" = bug。

**正确做法**：风格选定后，先过滤掉该风格的禁止 layout，再从允许 layout 中选版式。

## 使用流程

Step 5 选版式时：

1. 读取风格文件的 `## 页型配方` 和 `## 禁止构图`
2. 对照本表的允许/禁止 layout
3. 只从允许集合中选 layout
4. 数字页必须遵守该风格的数字页配方
5. 渲染后做灰度缩略测试

若某页型在禁止列表 **且** 业务需求强需要（如"必须有表格"） → 换风格（如从 coral-night 换到 heibai-ledger），不要换皮。
