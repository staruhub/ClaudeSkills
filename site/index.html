30-second install

Copy one skill. Keep control.

The installer copies the selected skill into your Claude Code skill directory. Read its source and capability row first.

Terminal 
git clone --depth 1 https://github.com/staruhub/ClaudeSkills.git
cd ClaudeSkills
python3 scripts/install_skill.py deck-studio

Choose another workflow: replace deck-studio with deep-research, product-manager, or wechat-article-writer.

Project-only install: add --project. List every installable short name with python3 scripts/install_skill.py --list.

Honest quality evidence

Know what passed—and what it did not prove

The repository separates static gates, model-based self-evaluation, and capability disclosure. It does not call them production proof.

Evidence Current scope Boundary
Structural gate Assertions for 13 curated skill directories Not output-quality or live-integration proof
Routing definitions 91 schema and conflict cases across 10 skills Not model-executed routing accuracy
Deck artifacts Generators, rendered pages, rubrics, scores, defects Model-based self-evaluation, not external certification
Capability matrix Per-skill reads, writes, network, shell, credentials, deletion Review third-party dependencies under your own policy

FAQ

Before you install

Is this a prompt collection?

No. Each curated skill is a folder with a SKILL.md instruction contract and, when needed, references, scripts, assets, and routing cases.

Do the checks mean every workflow is end-to-end verified?

No. The current L1 gates verify structure and routing-case consistency. Python files are compile-checked. Some workflows include deeper artifacts, but the repository does not claim live E2E coverage for all four flagships.

Why did my slash command get a long name?

The installed directory name becomes the slash command. Use the installer, which copies Geek-skills-deck-studio to deck-studio, or rename a manual copy yourself.

How do I contribute?

Start with an issue. New skills incubate in lab/ and graduate after they meet the repository's quality gates and capability disclosure rules.
